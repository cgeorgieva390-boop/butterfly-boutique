BUTTERFLY BOUTIQUE – БЕЗПЛАТЕН САЙТ

1. Регистрирай се безплатно на https://github.com/signup
2. Създай ново публично хранилище с име butterfly-boutique (или друго).
3. В хранилището натисни Add file -> Upload files и качи index.html и products.js от тази папка (не ZIP файла).
4. Settings -> Pages -> Build and deployment -> Deploy from a branch -> main -> /(root) -> Save.
5. Публичният линк ще бъде https://ТВОЯ-ПОТРЕБИТЕЛ.github.io/butterfly-boutique/ . Публикуването може да отнеме няколко минути.

ДОБАВЯНЕ НА ПАРФЮМИ:
В GitHub отвори products.js, натисни иконката с молив (Edit) и добави обект към списъка по образеца:
{id:'men01',name:'Име на мъжки парфюм',category:'men',price:20,image:'https://адрес-на-снимка.jpg',description:'Описание'}
category:'women' за дамски, category:'men' за мъжки. Не забравяй запетаи между обектите. Натисни Commit changes. Сайтът се обновява автоматично.
За снимки: качи JPG/PNG файлове в GitHub (например images/men01.jpg) и в products.js посочи image:'images/men01.jpg'.
